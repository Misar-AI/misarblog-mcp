# Misar.Blog agents

Task-scoped agents built on the @misarblog/mcp MCP server. Each bundles a subset
of the tools with the rules for using them safely.

| Agent | Purpose |
| --- | --- |
| `editorial-planner` | Plans a content calendar from existing coverage, analytics and search demand; sets up series. |
| `article-writer` | Researches, drafts and SEO-optimises an article, then saves it as a draft for review — never auto-publishes. |
| `audience-growth` | Reviews analytics, reactions and newsletter performance and recommends the next highest-impact action. |

All of them require authentication — see https://docs.misar.io/blog. Generated by
`scripts/mcp/generate-distribution.mjs`; edit the product entry, not these files.
